# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Technical disagreement is welcome; personal attacks are not.

Examples of expected behavior:

- focus criticism on code, behavior, evidence, and trade-offs
- assume good faith while still asking for evidence
- give actionable feedback
- respect privacy and avoid exposing personal information
- make room for contributors with different experience levels

Unacceptable behavior includes harassment, threats, discriminatory language, sexualized conduct, deliberate disruption, doxxing, and repeated personal attacks.

## Scope

This code of conduct applies to repository issues, pull requests, reviews, discussions, and other project spaces controlled by the maintainers.

## Enforcement

Project maintainers may edit, hide, lock, or remove content and may restrict participation when behavior repeatedly violates these standards.

If you need to report conduct privately, contact `@Majkey25` through GitHub without posting sensitive details publicly.
